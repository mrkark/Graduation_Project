# Шотокан: библиотека техник и 26 ката (v4)

## Что в пакете
| Файл | Содержимое |
|---|---|
| `karateka_techniques_v4.glb` (23 МБ) | персонаж + 213 клипов: прежние 92 + 121 новый (39 техник рук × 2 стороны, 10 ударов ногами × 2, 4 прыжка, новые стойки) |
| `kata_animation_only/kata_<имя>.glb` (26 файлов, ~2 МБ) | только анимация одного ката (без мешей): грузите вместе с моделью из библиотеки, кости совпадают по именам |

| `scripts_v4.zip` | движок: стойки/шаги/блоки/удары/прыжки + данные ката |
| `demo/` | контрольные листы (позы техник, удары ногами, прыжок Heian Godan, Empi, Hangetsu) |

60 fps, Root = 0 (смещение только у Hips), каналы 12 костей ткани запечены в каждый клип (в Three.js ничего симулировать не надо).

## Архитектура
Каждое ката — список из ~20–60 записей «поворот → стойка → техника(и)», собираемых из одних и тех же базовых блоков: `step_into` (шаг с фиксацией опорной стопы), `strike_in_place`, `do_kick`, `jump_seq`, пресеты рук (`tech2.py`, `tech3.py`). Новые стойки: heisoku, musubi, hachiji, uchi-hachiji, renoji, neko, kosa, hangetsu, sanchin, shiko, moto, tsuru. Блоки выполняются двумя руками (замах/hikite + блок).

## Выбранный вариант и достоверность
Вариант: JKA-подобный Shotokan. Источник — пошаговые описания themartialway.com.au (пересказ), для остальных — мои знания.
- **Есть пошаговый источник (высокая/средняя):** Heian Shodan, Sandan, Yondan, Godan, Tekki Shodan, Bassai Dai, Kanku Dai, Jion, Empi, Gankaku, Hangetsu, Meikyo, Ji'in, Unsu, Wankan.
- **Приближённо, по памяти (НИЗКАЯ достоверность):** Heian Nidan (описания источника противоречат друг другу), Tekki Nidan и Sandan, Jitte, Kanku Sho, Bassai Sho, Chinte, Sochin, Nijushiho, Gojushiho Sho и Dai. Источник дал только число движений и фирменные техники — последовательность и углы поворотов я восстановил сам. **Эти 10 ката нужно сверить с вашим инструктором/справочником JKA.**
- Во всех ката углы поворотов — моя интерпретация текста; число движений местами отличается от официального.

## Проверки
- Перегибы рук: у большинства ката нет; единичные места до 4–8 см (Gankaku 29–31, Unsu 12, Meikyo 25–26, Jitte 3, Gojushiho 25–26/31–32).
- Рывки суставов: после исправлений и адаптивного сглаживания ≤ ~42°/кадр в ката (до этого до 180°: развороты колен на 180° и руки в прыжках — исправлены в движке). В библиотеке единственные выбросы — юбка кимоно в прыжке на 360° (89°/кадр).
- Скольжения стоп и COM для новых ката отдельно не аудировались (шаги строятся с фиксацией опорной стопы, как в проверенных ранее клипах).

## Известные ограничения
- `.blend` не менялся (работа в GLB).
- Клиппинг ткани для новых клипов не прогонялся (для прежних 92 — был).
- Удары ногами: положение подъёма стопы (ребро стопы в yoko-geri, mawashi) приближённое; ushiro-geri и mikazuki-geri проще реальных.
- Упрощения: haiwan-uke/keito-uke/kake-dori/tsukami-uke заменены ближайшими блоками открытой кистью (haishu-uke); хваты с палкой (jo) в Meikyo заменены блоками; kasei-mawashi-geri в Unsu (с опорой на руки) — боковой mawashi-geri; kime-профиль скоростей не измерялся.
- Тёмные места: Tekki — перекрёстный шаг выполнен прямой траекторией ступни (без прохода «за» опорной ногой).
